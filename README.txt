MONKEYPHONES VOORRAAD- EN REPARATIEBEHEER
=========================================

Bestanden:
- index.html
- style.css
- script.js
- assets/

Gebruik (GitHub Pages):
1. Upload ALLE bestanden naar de hoofdmap van je GitHub repository.
2. Zorg dat index.html in de hoofdmap staat.
3. Zet GitHub Pages aan via Settings > Pages > Deploy from branch.
4. Kies de branch (meestal main) en de map /root.
5. Open daarna je GitHub Pages-adres.

Let op:
Voorraad en reparaties worden opgeslagen in de browser (localStorage) en zijn dus
NIET automatisch gedeeld tussen apparaten. Gebruik "Back-up" en "Herstel" links
onderin het menu om je gegevens te bewaren of naar een ander apparaat te verplaatsen.
